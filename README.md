# HR-Data-Analysis-SQL-Python
# Human Resources Data Analysis using SQL & Python

## 📌 Project Overview
This project focuses on analyzing a comprehensive HR dataset containing employee records to extract valuable workforce insights, salary distributions, and retention patterns. The entire workflow integrates SQL queries inside a Python notebook environment for scalable data analysis.

## 🛠️ Tech Stack
- **Database Querying:** SQL (via DuckDB engine)
- **Data Manipulation:** Python, Pandas, NumPy
- **Data Visualization:** Matplotlib, Seaborn
- **Environment:** Visual Studio Code (.ipynb)

## 📊 Key Insights Extracted
1. **Highest-Paying Roles:** Successfully identified the top 10 highest-paying positions across the organization using advanced SQL aggregation techniques.
2. **Employee Turnover:** Analyzed resignation and retention behaviors across different business departments.
3. **Data Cleaning:** Professionally handled missing values (`Null` counts) inside `ManagerID` and converted static parameters into dynamic categorical features using NumPy.
